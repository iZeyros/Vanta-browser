## Vanta 0.2.9

### Correctif
- **Installation impossible sur certains PC (erreur 0xc000007b ou « VCRUNTIME140.dll introuvable »)** : Vanta et son installateur dépendaient du paquet « Visual C++ Redistributable » de Microsoft. Sur un PC où il manque, ou où une copie 32 bits de ses fichiers traîne, Windows refusait de les lancer. Ce runtime est désormais intégré aux exécutables : plus rien à installer à côté.

Reprend toutes les nouveautés de la 0.2.8 (liste de souhaits et alertes de prix, protection contre les empreintes, bloqueur renforcé sur YouTube, moins de RAM).

### Texte « Nouveautés de cette version » pour le Microsoft Store (copier-coller)

Correctif : Vanta se lance sur tous les PC, sans dépendre du paquet Visual C++ de Microsoft. Liste de souhaits de jeux sur l'accueil avec alertes de prix : meilleur prix toutes boutiques (Steam, Epic, GOG, Humble…) et notification dès qu'un jeu passe en promo. Bloqueur renforcé sur YouTube : les pubs vidéo avant, pendant et après les vidéos sont bloquées grâce aux scriptlets de uBlock Origin. Nouvelle protection contre les empreintes (canvas, audio), signal Global Privacy Control et API publicitaires de Chromium désactivées. Raccourci du VPN : Ctrl+Maj+E. Moins de RAM quand Vanta est réduit.

### “What's new in this version” for the English Store listing (copy and paste)

Fix: Vanta now starts on every PC, without depending on Microsoft's Visual C++ package. Game wishlist on the start page with price alerts: best price across stores (Steam, Epic, GOG, Humble…) and a notification as soon as a game goes on sale. Stronger blocker on YouTube: video ads before, during and after videos are blocked thanks to uBlock Origin scriptlets. New fingerprinting protection (canvas, audio), Global Privacy Control signal and Chromium's advertising APIs disabled. VPN shortcut: Ctrl+Shift+E. Less RAM while Vanta is minimized.
